# 每周计划与验收模板

复制下面模板到自己的学习日志，每周只承诺一个可验收成果。

```markdown
# 第 N 周：主题

## 本周问题
- 我真正要回答的问题：
- 为什么值得回答：
- 先验预期与可能被证伪的条件：

## 输入
- 数据来源、获取日期、版本/快照：
- 阅读材料：
- 代码环境与提交：

## 计划（总计不超过 10 小时）
- 阅读：
- 编码：
- 实验：
- 复盘：

## 验收
- [ ] 代码可从空环境运行
- [ ] 输出有基准和单位
- [ ] 时间对齐已人工抽查
- [ ] 记录异常、失败和未解决问题
- [ ] 结论写明只适用于什么范围

## 复盘
- 最重要的新认知：
- 最危险的错误：
- 哪个结果改变了我的判断：
- 下周只改一件什么事：
```

## 每四周检查

1. 随机选一个旧实验，从 README 重跑；失败就修复环境或文档。
2. 抽查 10 个日期，证明特征、信号、下单、收益的时间关系。
3. 删除一个没有明确问题驱动的指标或图。
4. 写下目前最大的模型风险、数据风险和操作风险。
5. 让另一个人只看报告复述结论；若他把“相关”理解成“必赚”，重写摘要。
