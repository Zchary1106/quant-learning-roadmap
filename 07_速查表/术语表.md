# 量化术语表

- Alpha：相对于基准或风险模型不能解释的收益；定义依赖所选基准。
- Beta：资产对某风险因子/市场变动的敏感度。
- 因子：解释收益/风险差异的可度量特征或共同驱动。
- IC / Rank IC：因子与未来收益的截面相关 / 秩相关。
- Point-in-time：按历史当时真正可见的信息还原数据。
- 前视偏差：使用决策时尚不可见的信息。
- 幸存者偏差：只保留今天仍存在的对象。
- 数据窥探：反复查看结果并据此选择方案。
- 样本外：未用于拟合或选择的后续数据；一旦被用于迭代就不再纯净。
- Walk-forward：训练窗口和紧随其后的测试窗口不断向前滚动。
- Purge / Embargo：清除跨切分重叠标签，并在边界留隔离期的思想。
- 滑点：预期价格与实际/模拟成交价格的差异。
- 市场冲击：自身订单改变市场价格的成本。
- 换手：持仓变动程度，与成本和容量直接相关。
- 容量：在合理冲击与风险下可承载的资金规模，随市场状态变化。
- 最大回撤：财富从历史峰值到后续谷值的最大跌幅。
- 夏普比率：单位波动对应的平均超额收益，依赖统计假设且不描述尾部路径。
- Calmar：常见定义为年化收益 / 最大回撤绝对值。
- 中性化：降低行业、市值、市场等指定暴露。
- 协整：非平稳序列某线性组合平稳，不等同于普通相关。
- Paper trading：用实时或回放数据模拟订单与账户，不产生真实成交。
- Shadow mode：生产环境生成决策但不发送真实订单，用于对比验证。
- Kill switch：停止新增风险、撤销订单或关闭系统的确定性紧急机制。
