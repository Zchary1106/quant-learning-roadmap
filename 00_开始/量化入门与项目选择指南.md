# 量化入门与项目选择指南

本指南回答四个问题：量化到底在做什么、从哪里开始、该选哪个开源项目、怎样学得更快更扎实。项目与链接于 **2026-09-03** 使用公开网页和 GitHub API 核验；活跃度、Star、接口与许可证以后仍会变化。

## 1. 先理解什么是量化

量化不是“找一个指标自动赚钱”，而是把投资或交易想法写成可以检查的规则：

```text
假设 → 数据 → 特征/信号 → 组合与仓位 → 成交与成本
    → 回测 → 样本外验证 → 风险评估 → 模拟交易
```

例如“价格突破后可能延续”还不算策略。至少要继续明确：

- 使用什么资产、频率和历史区间？
- 突破如何定义，信号何时可见？
- 下一根开盘还是收盘成交？
- 仓位多大，何时退出？
- 费用、滑点、无法成交怎样处理？
- 和买入持有、现金或等权组合相比如何？
- 换一个时期、参数或成本后是否仍有证据？

量化的核心不是预测得神，而是让假设、数据、时序、成本和风险都能被复查。

## 2. 新手先选一条主线

| 方向 | 适合你，如果你更喜欢 | 第一个项目 | 暂时不要做 |
|---|---|---|---|
| 研究型（默认） | 数据、统计、因子、资产配置 | ETF 趋势策略或行业 ETF 动量 | 高频、复杂深度学习 |
| 工程型 | 系统、接口、性能、可靠性 | 事件驱动回测器和模拟券商 | 直接连接真实账户 |
| ML 型 | 特征、预测、模型比较 | 横截面排序或波动预测 | 强化学习自动下单 |

不知道怎么选就从研究型开始。它能训练数据质量、无泄漏验证和风险意识，以后转工程或 ML 都不会浪费。

## 3. 项目怎么选

不要同时安装十个框架。按当前阶段只选一个：

| 阶段 | 推荐项目 | 最适合学习 | 注意事项 |
|---|---|---|---|
| 零基础中文 | [Quant-for-Beginners](https://github.com/datawhalechina/quant-for-beginners) | Notebook、收益、均线、回测、风险与组合 | 适合建立直觉；高级因子和 AI 章节仍在规划 |
| 中文系统课程 | [WhaleQuant](https://datawhalechina.github.io/whale-quant/) | 数据、选股、择时、调仓、回测、ML | README 标注 Alpha；Python 3.9，CC BY-NC-SA 4.0 |
| 本地第一套实验 | [本仓库实验](../05_实验代码/README.md) | 指标、时序、成本、数据质量、walk-forward、尾部风险 | 代码故意保持小，适合逐行理解和改错 |
| 简单策略回测 | [backtesting.py](https://github.com/kernc/backtesting.py) | 快速写单资产策略、看 API 和图表 | AGPL-3.0；不要被快速调参诱导过拟合 |
| 资产配置 | [bt](https://github.com/pmorissette/bt) | 权重算法、再平衡、组合回测 | 先和等权基准比较 |
| 因子与 ML 研究 | [Qlib](https://github.com/microsoft/qlib) | 数据工作流、因子、模型、实验管理 | 规模较大；先完成一个线性基准 |
| ML 教材代码 | [Machine Learning for Trading](https://github.com/stefan-jansen/machine-learning-for-trading) | 从数据到特征、模型和策略评估 | 逐章重做，不要只运行 Notebook |
| 中国交易工程 | [VeighNa/vn.py](https://github.com/vnpy/vnpy) | 事件引擎、网关、订单和中国市场生态 | 先历史回放与 paper，不接真实资金 |
| 全栈架构 | [LEAN](https://github.com/QuantConnect/Lean) | 多资产、算法框架、组合与订单模型 | 代码库大，按模块阅读 |
| 高阶交易系统 | [NautilusTrader](https://github.com/nautechsystems/nautilus_trader) | 确定性事件驱动、回放、订单状态 | Rust 内核，上手成本高 |
| 加密市场专项 | [Freqtrade](https://github.com/freqtrade/freqtrade) | 加密回测、优化、部署 | 交易所、托管和 24/7 市场风险不同 |

推荐顺序：

```text
本仓库小实验
  → backtesting.py（策略）或 bt（组合）
  → Qlib（研究/ML）或 vn.py（工程）
  → LEAN / NautilusTrader（高阶架构）
```

只有当上一级项目能独立解释、加入测试并指出假设时，才进入下一级。

## 4. 必学知识地图

### Python 与数据

- Python 函数、类型提示、异常、虚拟环境、Git、pytest。
- NumPy 数组与向量化；pandas 索引、合并、分组、滚动窗口。
- SQL、CSV/Parquet、时区、交易日历、缺失值和数据版本。
- 推荐：[Python for Data Analysis 在线版](https://wesmckinney.com/book/)、[pandas 入门](https://pandas.pydata.org/docs/getting_started/index.html)。

### 数学与统计

- 收益与复利、概率、抽样、置信区间、协方差、线性回归。
- 平稳性、自相关、异方差、厚尾、时间切分、多重检验。
- 推荐：[OpenIntro Statistics](https://www.openintro.org/book/os/)、[ISLP](https://www.statlearning.com/)、[本地统计稳健性讲义](../02_核心讲义/12_统计推断与稳健性.md)。

### 金融与市场

- 股票、ETF、期货、期权的收益结构和交易单位。
- 订单、买卖价差、滑点、流动性、复权、公司行动、保证金。
- 中国市场还要理解涨跌停、停牌、集合竞价、印花税和夜盘交易日。

### 研究与回测

- 前视偏差、幸存者偏差、数据窥探、point-in-time 数据。
- 基准、成本、换手、walk-forward、purge/embargo、负对照。
- 收益之外报告波动、夏普、回撤、回撤持续时间、容量和尾部风险。

### 组合、风险与工程

- 等权、波动率倒数、风险贡献、约束、再平衡和压力测试。
- 信号、目标仓位、订单、成交、现金与实际持仓必须分开。
- 实盘前必须有监控、对账、幂等、恢复、限额和 kill switch。

## 5. 30 天启动计划

每天 60–90 分钟即可；目标不是赚钱，而是完成第一份可信研究。

### 第 1 周：能读数据、算收益

1. 完成[入学诊断](入学诊断与方向选择.md)。
2. 建立 Python 环境，运行 Lab 1。
3. 手算 5 个价格的收益、复利、最大回撤。
4. 用 pandas 读取一份 OHLCV，检查日期、重复、缺失和异常。

验收：你能解释为什么简单收益不能直接相加，以及短样本年化为什么不可靠。

### 第 2 周：做第一个基准研究

1. 运行 Lab 5，把真实数据写入 SQLite 三层表。
2. 完成买入持有基准，加入费用。
3. 画价格、净值、回撤和滚动波动。
4. 写数据卡，记录来源、日期、复权和已知问题。

验收：删除输出后，能从原始数据一条命令重建。

### 第 3 周：做一个简单策略

1. 运行 Lab 2，理解信号至少滞后一档。
2. 只预先选择 2–3 组均线参数。
3. 比较 0/5/10/20 bps 成本和买入持有。
4. 运行 Lab 6，只在训练窗口选参数。

验收：能画出“信息可见 → 信号 → 成交 → 收益”的时间线，不使用测试集调参。

### 第 4 周：验证、写报告、决定停止或继续

1. 运行 Lab 8，对区间和块长度做敏感性检查。
2. 检查不同年份、成本翻倍、参数邻域和负对照。
3. 使用[研究报告模板](../04_实践项目/研究报告模板.md)写完整报告。
4. 如果证据不足，明确停止；如果仍值得研究，只进入 paper trading。

验收：报告同时展示失败窗口、基准、成本、样本外和最大限制。

## 6. 怎样学得更好

1. **以作品而不是观看时长衡量学习。** 每周至少留下代码、测试、图和一页结论。
2. **70% 动手，20% 阅读，10% 视频。** 视频容易产生“听懂了”的错觉。
3. **每个概念都做正例、反例和边界测试。** 例如故意制造同日收益泄漏，确认测试会失败。
4. **一次只研究一个变化。** 同时换数据、特征、模型和成本后，无法知道改善来自哪里。
5. **先简单基准，再复杂模型。** ML 必须证明相对规则或线性模型的样本外增量。
6. **维护研究日志。** 记录假设、数据版本、全部试验、失败原因和下一步唯一实验。
7. **每四周重做一次旧项目。** 不看答案从零重建，才知道哪些知识真正掌握。
8. **读源码时画调用链。** 找到 Data → Strategy → Portfolio → Order → Fill，而不是从第一行读到最后一行。

## 7. 最常见的错误

- 一开始就追求“高收益策略”或复制别人的参数。
- 用今天的股票池回测过去，或按财报期而不是公告时间对齐。
- 同日收盘生成信号，又获得同日收益。
- 反复看测试集、只展示最优参数和最好区间。
- 忽略滑点、换手、涨跌停、停牌、容量和税费。
- 同时学习太多框架，却没有一份能重跑的研究报告。
- paper trading 一盈利就连接真实资金。
