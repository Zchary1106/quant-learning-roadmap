# 量化学习资料库

这是一套从零开始、以“能独立完成可信研究”为目标的 24 周中文学习包。它不是开户链接、荐股清单或收益承诺；核心能力是把想法变成可复现的数据、信号、回测、风险评估和模拟交易系统。

## 在线学习路线

访问 [24 周交互式学习路线](https://zchary1106.github.io/quant-learning-roadmap/)，可以切换研究型、工程型和机器学习型路线，并在浏览器本地记录每周完成状态。

## 建议使用顺序

1. 先做 [入学诊断](00_开始/入学诊断与方向选择.md)，确定每周投入时间与方向。
2. 按 [24 周路线图](01_学习路线/24周学习路线.md) 学习，用 [周计划模板](01_学习路线/每周计划与验收.md) 记录证据。
3. 每周阅读对应的 [核心讲义](02_核心讲义)，再访问 [外部课程与图书](03_资源索引/课程图书与论文.md)；进入策略评估阶段前，建议连读 [07_回测与科学验证](02_核心讲义/07_回测与科学验证.md) 与 [12_统计推断与稳健性](02_核心讲义/12_统计推断与稳健性.md)。
4. 第 3 周起运行 [实验代码](05_实验代码/README.md)，第 8 周起完成 [项目阶梯](04_实践项目/项目阶梯.md)。
5. 每个策略必须使用 [研究报告模板](04_实践项目/研究报告模板.md) 和 [上线检查表](04_实践项目/策略上线检查表.md)。
6. 每阶段完成 [40 道练习与进阶题](06_练习与答案/练习题.md)，再对照 [参考答案](06_练习与答案/参考答案.md)；外部资料的检查边界见 [核验记录](03_资源索引/核验记录.md)。

## 学习原则

- 先基准、后复杂：任何策略先和现金、买入持有、等权组合比较。
- 先防泄漏、后调参：时间穿越、幸存者偏差、复权错误会让漂亮曲线失真。
- 研究与实盘分离：回测结果只说明历史模拟，不等于未来收益。
- 记录失败：失败假设、异常数据、成本敏感性和停止条件都属于研究成果。
- 小额、低频、可撤销：在纸上交易稳定之前不进入真实资金；进入后也先验证基础设施。

## 推荐默认路径

如果暂时不知道选哪条路线，选择“研究型”：Python + 统计 → 数据清洗 → 因子/策略 → 严谨回测 → 组合与风险 → 纸上交易。它最容易建立可迁移的判断力，也能自然转向工程或机器学习。

> 风险声明：本资料仅用于教育和技术研究，不构成投资建议。真实交易会发生滑点、费用、流动性约束、制度限制和本金损失。
