# 策略上线检查表

此表的“上线”先指 paper/shadow。真实资金是另一个明确批准的阶段。

## 研究闸门

- [ ] 机制可解释，并有简单基准
- [ ] 数据 point-in-time；时间线人工抽查
- [ ] 参数和试验总数有记录
- [ ] 未触碰样本外、walk-forward、子区间均已报告
- [ ] 费用、滑点、延迟、容量和无法成交已建模
- [ ] 结果不是单资产/单时期/单参数支撑
- [ ] 失败、限制和证伪条件写入报告

## 工程闸门

- [ ] 环境、数据、配置、代码可重放
- [ ] 指标、对齐、订单状态机有单元/集成测试
- [ ] 重复事件幂等；部分成交/拒单/断线已测试
- [ ] 启动时完成账户、持仓、订单对账
- [ ] 目标与实际持仓持续监控
- [ ] 数据陈旧、时钟偏移、风险超限时 fail closed
- [ ] 日志可审计且不泄露密钥

## 风险与安全闸门

- [ ] 资产白名单、最大订单、最大仓位、最大日成交量参与率
- [ ] 组合/策略风险预算和分级降险
- [ ] kill switch 已演练，人工接管人明确
- [ ] 交易密钥最小权限、不可提款、账户隔离
- [ ] 券商/交易所/数据许可/当地规则已按当前日期核对
- [ ] 故障手册、告警级别和联系人完整

## 分阶段发布

历史回放 → paper → shadow → 极小资金 → 分级扩容。每阶段写最短观察周期、最大允许偏差和回退条件。只要出现无法解释的持仓/订单/数据差异，就停止新增风险并对账。
