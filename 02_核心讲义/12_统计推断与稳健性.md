# 12 统计推断与稳健性

## 先说结论

这些工具不是给策略“盖章”，而是把“看起来有效”拆成更可检查的不确定性：收益依赖结构、样本偶然性、重复试验、研究者自由度、样本外脆弱性。做完这些检查，结论仍然可能失效；但不做，通常只会更乐观。

## 金融收益很少满足独立同分布

研究里最常见的偷懒是假设每个观测都像独立掷硬币。但金融收益常同时违反“独立”和“同分布”：

- **自相关**：持仓延续、分批成交、趋势/反转、平滑估值都会让今天和昨天相关。
- **异方差**：平静期和危机期波动完全不是一个量级。
- **厚尾与偏度**：极端亏损比正态分布下更常见。
- **结构变化**：制度、流动性、参与者和成本会变。
- **重叠收益**：例如 5 日持有期每天滚动开仓，样本彼此天然重叠。

直接后果：

- 普通标准误和 `t` 值常常偏乐观。
- 直接按 `sqrt(252)` 年化夏普可能失真。
- 把日期随意打乱做重采样，往往破坏了最重要的依赖结构。
- 只靠一个样本区间的结果，很难知道优势是机制还是运气。

实务里先问四个问题：

1. 观测单位是什么：单日收益、单笔交易、滚动持有期收益，还是回归残差？
2. 收益是否重叠？
3. 波动和流动性是否明显分 regime？
4. 你要估计的是**线性统计量的不确定性**，还是**整条策略流程产出的分布**？

这四个问题基本决定后面更适合用 HAC/Newey-West 还是块 bootstrap。

## 块 bootstrap：保留“连续性”，而不是把日期洗牌

### 直觉

普通 bootstrap 是按单个观测抽样，默认观测彼此可交换；时间序列通常不满足。**块 bootstrap** 的做法是抽取一段一段连续时间块，再拼成新样本，让局部自相关、波动聚集和市场状态不被完全打碎。

### 适合回答什么

当你关心的是整条策略流程的结果分布，而不只是某个线性系数的标准误时，块 bootstrap 往往更实用，例如：

- 均值收益、净收益、夏普的区间估计
- 最大回撤、回撤持续时间
- 胜率、盈亏比、换手后的净表现
- 成本翻倍后指标是否仍站得住

### 实务上怎么用

- **按时间块抽样，不要按单日抽样。**
- **多资产面板要整块一起抽**，不要把不同资产日期分别抽乱，否则横截面共振关系会被破坏。
- **块长至少要覆盖主要依赖尺度**：常从平均持有期、信号衰减期、自相关衰减期出发，而不是机械套公式。
- **每次重采样都重跑完整指标管线**：包括信号、持仓、成本和风险指标，而不是只对最后的夏普做手工修补。
- 看的是**分布**，不是只看一次重采样后的幸运结果。通常至少报告中位数、5%/95% 分位数，或更保守的置信区间。

### 边界与常见误用

- 它**不能制造没见过的危机**。历史里没有的 regime，不会被 bootstrap 凭空补出来。
- 块长太短会重新接近“单日打乱”，太长则有效样本太少。
- 当样本本来就很短、危机窗口只有一两段时，区间会非常不稳定；这不是方法失败，而是证据本来就弱。
- 它不能修复前视偏差、幸存者偏差、错误成本模型。

## HAC / Newey-West：修的是标准误，不是世界

### 直觉

HAC（Heteroskedasticity and Autocorrelation Consistent）/ Newey-West 的核心想法是：即使残差存在**异方差**和**若干阶自相关**，我们仍然可以用“长期方差”来替代天真的样本方差，从而得到更稳健的标准误。

可以把它理解为：

**不是说你的均值或回归系数一定对，而是说“你有多确定它不等于 0”这件事，不能继续用 i.i.d. 的尺子量。**

### 更适合的场景

- 固定策略平均收益是否显著高于 0
- 预测回归的系数和 `t` 值
- 存在**重叠收益**的回归或事件研究
- 想保留原始时间顺序，只修正推断的标准误

### 一句数学直觉

普通标准误只看当期方差；Newey-West 会把若干滞后自协方差也加进来，并对更远的滞后赋更小权重。

所以如果收益正自相关，长期方差通常会比天真的单期方差更大，显著性也就会下降。

### 适用边界

- 它主要修正**标准误**，**不修正系数偏误**。如果模型本身错了、变量有内生性、价格水平非平稳、标签泄漏，HAC 无能为力。
- 滞后阶数选太小会继续乐观，选太大则会让估计很噪。
- 小样本下 HAC 很脆弱，尤其是你一边调模型一边再看 `t` 值时。
- 对最大回撤、Calmar、路径依赖止损等**强非线性指标**，HAC 不是首选；块 bootstrap 往往更自然。

## 块 bootstrap 和 HAC 该怎么选

| 你要回答的问题 | 更常见的第一选择 | 原因 |
|---|---|---|
| 固定策略均值收益是否显著 | HAC / Newey-West | 直接针对均值或回归系数的标准误 |
| 预测回归、重叠持有期回归 | HAC / Newey-West | 时间顺序保留，修正异方差和自相关 |
| 夏普、最大回撤、回撤持续时间区间 | 块 bootstrap | 指标非线性、路径依赖明显 |
| 完整回测流程在重采样下是否稳定 | 块 bootstrap | 可重跑整条策略管线 |
| 样本很短且 regime 很少 | 两者都要谨慎 | 工具无法替代缺失证据 |

一个实用做法是：**线性统计量先看 HAC，路径依赖和整流程稳定性再看块 bootstrap。**

## 夏普比率的不确定性：不要只报一个点估计

夏普比率本质上是“样本均值 / 样本波动”。问题在于：均值和波动都要估，且收益还可能有自相关、偏度、厚尾和制度变化。所以一个年化夏普 `1.4`，远远不够支持研究结论。

至少补四类信息：

- **样本长度与频率**：3 个月日频的夏普，和 10 年月频的夏普，不确定性完全不同。
- **净值口径**：毛收益、净收益、是否包含滑点、冲击、借券和融资。
- **依赖结构**：是否存在明显自相关、重叠收益、平滑估值。
- **区间而非点**：用 HAC 调整后的推断，或块 bootstrap 区间，说明夏普的置信范围。

常见误区：

- **直接 `sqrt(252)` 年化**：这隐含独立性。若收益正自相关，年化夏普通常被抬高。
- **平滑收益误导**：低频估值、冷门资产或分批成交，容易让波动看起来过低，从而抬高夏普。
- **只看夏普不看左尾**：两个夏普相同的策略，负偏度和尾部风险可能完全不同。

研究报告里至少应同时给出：

- 样本内/样本外夏普
- 子区间夏普或年度夏普分布
- 净值曲线与最大回撤
- 一种稳健不确定性刻画（HAC 或块 bootstrap）

## 多重检验：FWER 与 FDR 不是一回事

当你测试很多因子、参数和过滤条件时，**总会出现偶然赢家**。这时要先区分两个目标。

### FWER：控制“出现任何假阳性”的概率

FWER（Family-Wise Error Rate）关注的是：在一整组检验里，**哪怕只有一个**误报都算坏事。

典型方法是 Bonferroni、Holm。它们偏保守，适合：

- 最终要提交一个很短的候选列表
- 误报代价很高
- 你宁愿错过一些真机会，也不想把伪信号带进实盘

### FDR：控制“入选者里假阳性的占比”

FDR（False Discovery Rate）关注的是：你挑出来的这些信号里，平均有多大比例是假的。

Benjamini-Hochberg 一类方法更适合：

- 同时筛很多因子或特征
- 目标是做“研究筛选”，不是立刻上线
- 你接受一定比例误报，但想把整体噪声压下去

### 实务规则

- **先定义检验家族**：例如“同一份数据、同一标签、同一主指标下的一整轮参数扫描”应视为同一家族。
- **记录全部试验数**：不是只记录最后留下来的几个。
- **同时报告原始 p 值与调整后结果**。
- **保留一个最终未触碰样本外集**，因为 FWER/FDR 只处理“你统计上承认的重复试验”，处理不了你临场改规则的自由度。

### 边界

- 很多方法对检验依赖结构有前提；现实中的因子和参数常高度相关。
- 如果你在看图以后又改标签、改成本、改交易规则，真正的“试验数”通常比你纸面写的更大。
- 多重检验调整能减少自欺，**不能证明真有可交易优势**。

## Deflated Sharpe 与 PBO：它们在审问“最好结果是不是挑出来的”

### Deflated Sharpe Ratio（DSR）

DSR 关注的问题是：

**在试了很多版本、而且收益分布可能偏离正态的前提下，你观察到的最佳夏普，是否仍然足够“意外”？**

它的用途：

- 给“最佳夏普”降温，而不是只看那个最大值
- 把样本长度、偏度、峰度、重复试验压力一起纳入考虑
- 适合大量参数扫描、策略库比较、模型选优后的复核

它的局限：

- **最难的是试验数怎么数**。300 个参数格点、10 个很像的变体，未必等于 310 个独立试验。
- 如果原始回测有泄漏、费用过低、成交假设错误，DSR 再漂亮也没意义。
- DSR 主要是“选择偏差审计”，不是完整的样本外验证。

### PBO（Probability of Backtest Overfitting）

PBO 关心的是：

**一个在样本内被选为赢家的策略，到了样本外变成差生的概率有多高？**

它通常通过时间切块和组合式交叉验证，观察“样本内排名靠前”的策略在样本外落到什么分位。

它的用途：

- 衡量模型选择流程是否过度偏爱样本内赢家
- 比较复杂流程和简单基准谁更容易过拟合
- 作为“上线前警报”，而不是上线许可证

它的局限：

- 时间切分方案会显著影响结果；金融数据不能随意做 i.i.d. 式交叉验证。
- 数据太短、regime 太少时，PBO 估计本身也不稳。
- PBO 告诉你“选优流程多危险”，不保证剩下的赢家就有效。

实务上，DSR 与 PBO 更像**审计工具**：它们能告诉你“这里很可能选优过头了”，但不能告诉你“这条策略以后一定行”。

## 负对照：先证明不是流水线自己在发明信号

负对照的目标不是让策略赚钱，而是让一个**理论上不该有效**的版本跑出来接近无效。如果负对照也能赚钱，优先怀疑流程。

常见做法：

- **时间错位**：把信号整体错到一个理论上不该有预测力的窗口。
- **块内随机化**：在保留季节性或波动结构的前提下，对信号日期做块内重排。
- **替换为伪因子**：保留分布形状，但打破与未来收益的真实对应关系。
- **换到无机制资产组**：例如一个只对财报后漂移有机制解释的信号，拿去测试明显不受该机制驱动的标的。

负对照失败时，优先检查：

- 标签泄漏
- 时间戳错位
- 成本漏算
- 存活样本/复权问题
- 共享数据处理造成的隐性前视

## 预注册：把“探索”与“确认”分开

预注册不是学术仪式感，而是为了减少“看到结果以后再改问题”。

在本仓库里，一个最小预注册文档至少应写清：

- 假设与机制：为什么这个信号可能有用
- 数据范围、可见时间、排除规则
- 主指标：例如净夏普、最大回撤、换手后的收益
- 主要对照：现金、买入持有、简单基准
- 多重检验计划：准备扫描哪些参数，检验家族如何定义
- 停止条件：什么结果出现就判定该想法暂不继续

预注册**不禁止探索**。更好的做法是明确区分两类结论：

- **探索性**：用来生成新假设，不拿来直接下部署结论
- **确认性**：按事先写好的规则，只在最终样本外上看一次

## 一套更实用的最小稳健性流程

1. 先写假设、样本、成本、主指标和停止条件。
2. 先跑最简单基准，再跑复杂版本。
3. 如果收益有重叠或明显自相关，均值/回归推断优先看 HAC。
4. 对夏普、回撤和整条策略流程，用块 bootstrap 看区间和分布。
5. 记录完整搜索空间，并做 FWER/FDR 调整。
6. 参数扫描很多时，再用 DSR 或 PBO 审计“最佳结果”是否过热。
7. 用负对照和最终样本外集检查：优势是否只是流水线、图形筛选或一次性 luck。

这套流程也**不能保证有效**，但能把“我只是挑到了最好看的那条曲线”的概率压低。

## 可执行检查清单

### 开始前

- [ ] 写出机制假设，而不是只写“这个因子相关性不错”。
- [ ] 定义观测单位、持有期、是否存在重叠收益。
- [ ] 固定主指标、成本口径、基准和停止条件。
- [ ] 留出最终未触碰样本外集。

### 研究中

- [ ] 记录所有参数、过滤器、标签和数据版本尝试。
- [ ] 对固定策略均值/回归显著性，至少看一次 HAC/Newey-West。
- [ ] 对夏普、回撤和净绩效，至少做一次块 bootstrap。
- [ ] 报告毛收益和净收益，不只报其中一个。
- [ ] 看参数邻域、子区间、不同市场状态，而不是只看最优点。
- [ ] 至少做一个负对照，确认不是流程自带 alpha。

### 下结论前

- [ ] 明确这轮搜索属于哪个检验家族，并报告试验总数。
- [ ] 说明选择 FWER 还是 FDR，以及为什么。
- [ ] 若进行了大规模选优，补充 DSR、PBO 或至少解释为何暂不适用。
- [ ] 报告主要限制：样本短、危机少、成本粗糙、估值平滑、容量未知等。
- [ ] 结论写成“当前证据支持到什么程度”，而不是“方法已证明有效”。

## 最后一句

稳健性工作不是为了把结论变成“肯定”，而是为了更快识别：哪些结果只是幸运、哪些是泄漏、哪些是参数挖矿、哪些值得继续花时间做样本外验证。
