# 02 Python 与数据工具

## 最小技术栈

- Python：函数、迭代、异常、类型提示、包与虚拟环境。
- NumPy：数组、广播、掩码、随机模拟、线性代数。
- pandas：索引、时间序列、连接、分组、滚动窗口、缺失值。
- Matplotlib/Seaborn：分布、时序、回撤、散点和诊断图。
- SciPy/statsmodels：统计检验、回归、时间序列。
- scikit-learn：管道、预处理、模型、时间切分和指标。
- SQLite/DuckDB：可查询的数据快照；Git/pytest：复现与回归测试。

## 时间序列的三个对象

不要把时间只当普通列：

1. `event_time`：市场事件真实发生时间；
2. `available_time`：研究者/系统最早能看到它的时间；
3. `decision_time`：策略作出决定的时间。

若财报期末是 3 月 31 日、公告在 4 月 25 日，那么 4 月 1 日不能使用这份数据。数据库中同时保存报告期与公告时间。

## pandas 对齐陷阱

- 算术会按标签对齐，不是按行号；合并后检查行数、唯一键与重复率。
- `rolling(n)` 是 n 行，不一定是 n 个自然日。
- `shift(1)` 的方向要用 3–5 行玩具数据人工验证。
- 不要对全样本 `fillna` 或标准化后再切训练集。
- 时区、交易日历、夏令时和跨市场收盘时间必须显式记录。

## 可复现项目骨架

```text
project/
  README.md              # 从零运行命令
  pyproject.toml          # 依赖与工具配置
  data/raw/               # 只读快照，不进 Git 的大文件
  data/processed/         # 确定性清洗结果
  src/                    # 可测试逻辑
  notebooks/              # 探索，不承载唯一实现
  tests/                  # 指标、对齐、边界测试
  reports/                # 图、表、结论
```

Notebook 适合探索，最终逻辑应下沉到函数并测试。用配置记录资产池、日期、费用和随机种子；输出中保存代码版本与数据快照标识。
