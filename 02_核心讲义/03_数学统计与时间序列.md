# 03 数学、统计与时间序列

## 必会而非“全学完”

### 收益与复利

简单收益 `r_t = P_t/P_{t-1}-1`；多期财富是 `Π(1+r_t)`。对数收益 `g_t = ln(P_t/P_{t-1})` 可相加，但真实财富仍需指数还原。不要直接把日简单收益相加当累计收益。

### 期望、风险与相关

均值描述中心但对厚尾不稳健；方差惩罚上下波动；协方差决定组合分散化。零相关不等于独立，历史相关在危机期可能上升。分位数、最大回撤和压力情景补充标准差。

### 抽样与不确定性

样本均值不是“真均值”。金融收益常有自相关、异方差、厚尾，经典独立同分布假设容易过于乐观。时间序列可用滚动/块式重采样表达不确定性，不要随意打乱日期。

### 回归

`y = Xβ + ε`。关注：系数符号与量级、标准误、残差结构、共线性、样本外误差。高 `R²` 不等于可交易，更不代表因果；在非平稳价格水平上回归尤其容易伪相关。

### 时间序列

- 平稳性：统计性质是否随时间稳定；价格常非平稳，收益更接近平稳但波动会聚集。
- 自相关：序列和自身滞后值的关系；高频数据会受微结构影响。
- 波动聚集：大波动常跟随大波动，可用滚动波动或 GARCH 类模型描述。
- 协整：某些非平稳序列的线性组合可能平稳；必须有机制并检验结构变化。

## 多重检验

测试 1,000 个无效信号，总会有少数看似显著。缓解办法：减少自由度、预注册、保留最终样本外集、报告试验总数、调整多重检验、考察经济意义和参数邻域，而不是只看单个 p 值。

## 建议掌握顺序

描述统计 → 概率与抽样 → 置信区间 → 线性代数 → 回归 → 时间序列 → 优化。每个概念都用模拟数据和真实数据各做一次。
