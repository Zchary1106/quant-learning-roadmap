# 数据源清单与选择表

## 先选数据层级

| 层级 | 用途 | 要求 |
|---|---|---|
| 教学/原型 | 学 API、指标和回测 | 可接受偶发字段变化；保存快照并抽查 |
| 严肃研究 | 做可发表/可复现结论 | point-in-time、退市覆盖、公司行动、许可清晰 |
| 模拟/实盘 | 驱动实时决策 | 服务等级、低延迟、重传、监控、明确交易授权 |

不要用教学接口直接跨越到实盘。

## 中国市场

- [上海证券交易所](https://www.sse.com.cn/)、[深圳证券交易所](https://www.szse.cn/)、[中国金融期货交易所](http://www.cffex.com.cn/)：产品规则、公告和部分行情的主来源。
- [中国证监会](http://www.csrc.gov.cn/)：监管文件主来源。
- [AKShare](https://akshare.akfamily.xyz/)：统一大量公开接口，适合教学/原型；字段和上游可能变化。
- [Tushare](https://tushare.pro/)：Token/积分型接口；使用前核对当前权限、许可和字段说明。
- 券商/期货公司接口：模拟和实盘的最终成交/账户来源；需要账户、协议和风控配置。

## 全球与宏观

- [FRED](https://fred.stlouisfed.org/)：美国及全球宏观序列；注意发布日期、修订和频率。
- [SEC EDGAR](https://www.sec.gov/edgar/search/)：美国公司申报主来源；遵守访问速率与标识要求。
- [Kenneth French Data Library](https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/data_library.html)：因子研究与基准数据。
- [Nasdaq Data Link](https://data.nasdaq.com/)：免费/付费数据集入口，许可因数据集而异。
- [Alpha Vantage](https://www.alphavantage.co/documentation/)：教学 API；有速率/套餐限制。
- [Stooq](https://stooq.com/q/d/?s=aapl.us&i=d)：历史行情下载入口；核对品种、复权和使用条款。
- `yfinance`：非 Yahoo 官方库，适合快速教学；数据权利和可用性受 Yahoo 条款与页面变化影响。

## 每个数据集必须有的数据卡

```yaml
name: 数据集名称
source_url: 原始入口
provider: 提供方
retrieved_at: 获取时间与时区
license_terms: 许可/条款链接
coverage: 资产、市场、起止时间
frequency: 日/分钟/tick
timezone_calendar: 时区与交易日历
point_in_time: 是否按当时可见
corporate_actions: 分红拆股退市处理
fields: 字段、单位、币种
missing_semantics: 缺失值含义
known_issues: 已知异常
checksum_or_version: 快照标识
```

## 交叉验证清单

抽 3 个资产 × 10 个日期：比较第二来源；核对拆股/分红日；核对成交量单位；检查极端收益；确认时区和交易日；确认退市资产；确认财务公告时间。差异未解释前，不进入调参。
