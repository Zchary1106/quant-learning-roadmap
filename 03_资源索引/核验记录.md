## 论文引用语义核验

通过 Crossref API 按 DOI 校对标题、作者和出版元数据：

- `10.1111/j.1540-6261.1993.tb04702.x` → Jegadeesh & Titman, *Returns to Buying Winners and Selling Losers...*
- `10.1016/0304-405X(93)90023-5` → Fama & French, *Common risk factors...*
- `10.2469/faj.v58.n4.2453` → Andrew Lo, *The Statistics of Sharpe Ratios*
- `10.1093/rfs/hhv059` → Harvey, Liu & Zhu, *... and the Cross-Section of Expected Returns*

核验过程中发现原写入的 `10.1093/rfs/hhu117` 实际对应 *Forthcoming Articles*，已纠正为 `hhv059`。这说明链接状态检查不能替代题名/作者语义核验。

SSRN 的两个入口在自动访问中返回 403，资料库只把它们列为待读入口，没有声称已下载或逐页核对全文。

全量 Markdown 外链审计共提取 57 个 URL：49 个直接返回 200；出版社 DOI、SSRN 与 SEC 等 6 个入口对自动客户端返回 403；FRED 一次读取超时。审计还发现 Fama–French DOI 中的圆括号会被 Markdown 解析器提前截断，已编码为 `%28`/`%29`，随后按规范 DOI 重新校对。403 或超时只记为“自动访问受限”，不等同于页面失效。

## GitHub 项目核验

使用 GitHub 公共仓库 API 读取 `stargazers_count`、`archived`、`pushed_at`、`license.spdx_id`、主语言与描述。项目表中的数字是约数和日期快照。

- `wtpyquant/wtpy` 初始猜测路径返回 404；搜索确认官方相关仓库为 `wondertrader/wondertrader` 与 `wondertrader/wtpy`，索引采用主仓库。
- vectorbt 的 API 许可证为 `NOASSERTION`；进一步读取仓库 `LICENSE.md` 确认为 Commons Clause 条件，故未标成 Apache/MIT。
- RQAlpha 的 API 同样为 `NOASSERTION`；仓库 `LICENSE` 区分非商业和商业用途，索引明确提示阅读自定义许可。
- PyAlgoTrade 的 API `archived=true`；原 Zipline 与 Backtrader 最近代码推送明显弱于替代项目，故只列历史阅读。

## 本地代码核验

- 首次 `pip install -e '.[dev]'` 失败：setuptools 将 `labs` 识别为额外顶层包，且本机默认 Python 为 3.9。
- 修复：包发现限定为 `quantlearn*`，兼容下限调整到实际可运行的 Python 3.9。
- 第二次运行发现 Rank IC 的 pandas `method='spearman'` 隐式依赖未声明的 SciPy；改为“先 rank，再 Pearson”，保持最小依赖。
- 最终：隔离 `.venv` 中安装成功；`pytest -q` 为 **9 passed**；4 个实验脚本均以退出码 0 完成。
